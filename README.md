# 🎬 YouTube Video Downloader (Python + Tkinter + yt-dlp)

A simple desktop app built with **Python (Tkinter UI)** and **yt-dlp** that lets you download YouTube videos with **video + audio combined (MP4)**.  

---

## 🚀 Features
- Simple graphical user interface (GUI).
- Paste any YouTube URL and download.
- **Video + Audio combined automatically** (MP4).
- Choose your own save location.
- Status updates in the UI.

---

## 📦 Requirements
Before running the app, make sure you have:

- [Python 3.8+](https://www.python.org/downloads/) installed  
- `pip` (comes with Python)  
- `yt-dlp` (YouTube downloader library)  
- `ffmpeg` (to merge video + audio in high quality)
